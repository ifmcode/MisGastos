# Session Note: Native Google Sign-In

**Date:** 07/11/2026
**Status:** ✅ Code + APK done / ⏳ Firebase console setup pending

## Summary

Web Google sign-in kept using the Firebase popup. Android/iOS now use the
native Google consent screen through `@react-native-google-signin/google-signin`
and exchange the returned ID token with
`signInWithCredential(GoogleAuthProvider.credential(idToken))`.

`signInWithPopup` does not exist on native, and Expo Go cannot load native
modules, so **Google sign-in requires a development build** (`expo run:android`
or EAS). In Expo Go the app does not crash: the Google button shows an inline
message explaining that a development build is required.

## Architecture

| File | Role |
|---|---|
| `features/auth/services/google-signin.service.ts` | Native flow (lazy-loads the native module, configures `webClientId`, maps cancellation/Play Services/ID-token errors) |
| `features/auth/services/google-signin.service.web.ts` | Web flow (`signInWithPopup`) |
| `features/auth/repositories/firebase-auth.repository.ts` | Calls the platform service, then syncs the Firestore profile |
| `lib/firebase.ts` | Native Auth with `getReactNativePersistence(AsyncStorage)` |
| `lib/firebase.web.ts` | Web Auth with `getAuth(app)` |

Metro picks `.web.ts` on web and `.ts` on native; TypeScript only needs the
shared signature (`signInWithGoogle(): Promise<User>`).

## Required external setup (one time)

1. **Firebase → Add Android app**
   - Package name: `com.misgastos.app` (must match `app.json`)
   - Debug SHA-1:
     `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25`
     (from `android/app/debug.keystore`, alias `androiddebugkey`; this is the
     certificate that actually signs the generated APK)
   - This creates the Android OAuth client in the Firebase Google Cloud project.
2. **Firebase → Authentication → Sign-in method → Google → Web SDK
   configuration → Web client ID**: copy the
   `...apps.googleusercontent.com` value.
3. Put it in `.env`:
   ```dotenv
   EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=<web-client-id>
   ```
4. Restart Metro so the variable is inlined.

`google-services.json` is **not** required: no Firebase native SDK is used and
the library only needs `webClientId` plus the registered Android OAuth client.
The config plugin is added without `android.googleServicesFile`, so prebuild
no-ops instead of failing.

## Development build

```powershell
npx expo prebuild --platform android
npx expo run:android
# or, if the android/ folder already exists:
npx expo start --dev-client
```

Expo Go is not supported for this feature.

## Windows build caveat (MAX_PATH)

CMake/ninja (3.22.1) cannot `mkdir` paths over 260 characters. `expo prebuild`
places module build dirs under `node_modules`, and the gesture-handler codegen
paths exceed the limit (`ninja: error: mkdir(...): No such file or directory`).

Working recipe used on this machine:

1. Build from a short root (e.g. copy the repo to `C:\mg2`).
2. Add to `android/app/build.gradle`:
   ```gradle
   android {
       externalNativeBuild {
           cmake {
               buildStagingDirectory = file("C:/b/app")
           }
       }
   }
   ```
3. Build only the needed ABIs:
   ```powershell
   .\gradlew.bat :app:assembleDebug -PreactNativeArchitectures=arm64-v8a,x86_64
   ```

`android/` is gitignored and regenerated by prebuild, so both tweaks stay local.
On macOS/Linux or EAS Build none of this is needed.
