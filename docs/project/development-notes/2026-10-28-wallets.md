## Summary

Implemented the wallets MVP with create/list flows, per-wallet balance display, include-in-total support, validation and Firestore persistence.

## Architecture

Feature-first layout under `features/wallets/`:

| Layer | Files |
|---|---|
| Types | `types/wallet.types.ts` |
| Validation | `schemas/wallet.schema.ts` |
| Utilities | `utils/money.ts`, `utils/wallet-options.ts` |
| Repository | `repositories/wallet.repository.ts`, `firebase-wallet.repository.ts`, `wallet.mapper.ts` |
| Service | `services/wallet.service.ts`, `wallet.errors.ts`, `wallet.factory.ts` |
| Hooks | `hooks/use-wallets.ts`, `use-wallet-service.ts` |
| UI | `components/wallets-screen.tsx`, `wallet-form.tsx`, `wallet-card.tsx`, `wallet-summary.tsx` |
| Route | `app/(tabs)/wallets.tsx` |

- Services depend on `IWalletRepository`, not Firebase directly.
- Firestore access is isolated in `FirebaseWalletRepository`.
- Components only orchestrate UI; validation and business rules live in the schema/service.

## Data and persistence

- Firestore path: root `wallets` collection (`wallets/{walletId}`).
- Each document stores `ownerId`, `initialBalance`, `balance`, timestamps and wallet metadata.
- `balance` is initialized from `initialBalance` (or 0 when empty).
- `getWallets` queries by `ownerId` and sorts by `createdAt` descending in the repository.

## Money decision

Amounts are stored as decimal numbers rounded to 2 decimals. Input accepts comma or dot as decimal separator, rejects negatives and more than 2 decimals. Calculations use `roundMoney` to reduce float drift. Integer cents remain an option before transactions/transfers if needed.

## Validation

Client and business validation share `validateWalletInput`:

- Name required, trimmed, max 40 characters.
- Currency must exist in `CURRENCIES`.
- Initial balance >= 0, finite, max 2 decimals.
- Type must be `cash`, `bank` or `other`.
- Icon must belong to the predefined Ionicons set.
- Color must be a 6-digit hex value.
- Description optional, max 160 characters.
- `includeInTotal` must be a boolean.
