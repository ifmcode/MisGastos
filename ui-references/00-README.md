# UI REFERENCES

Carpeta para guardar referencias de UI generadas con Google Stitch u otras herramientas.

## Uso
1. Guardar HTML exportado de Stitch aquí (ej: `dashboard.html`, `wallets.html`)
2. Nombrar descriptivamente
3. Mencionar en tickets/plan qué pantalla referencia
4. Puedes pedirle al agente que analice el HTML y genere componentes siguiendo `directrices/`

## Notas
- Mantener archivos organizados
- Añadir captura/descripcion si HTML poco claro
- Priorizar adaptar a estructura feature-first + UI Kit
